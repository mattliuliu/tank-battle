# 坦克大战 Tank Battle

一个使用原生 HTML + Canvas 实现的经典「坦克大战」（Battle City）小游戏，单文件即可运行，无需任何依赖。

## 玩法

- 控制我方坦克，击毁不断来袭的敌方坦克，保护基地（老鹰）。
- 每关敌人全部消灭后进入下一关，敌人会越来越快、越来越多。
- 砖墙可被子弹摧毁，钢铁墙无法摧毁，基地被击中则游戏结束。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动坦克 |
| `空格` / `J` | 射击 |
| `Enter` | 开始 / 重新开始 |
| `R` | 重新开始 |
| `M` | 静音开关 |

## 运行

直接用浏览器打开 `index.html` 即可：

```bash
# 任选其一
start index.html        # Windows
open index.html         # macOS
```

## 技术说明

- 纯 HTML5 Canvas 2D 绘制，无外部库、无构建步骤。
- 游戏逻辑全部内嵌在单个 `index.html` 中。
